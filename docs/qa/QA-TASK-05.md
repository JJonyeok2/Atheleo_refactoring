## 세부 확인
- aspectRatio 방향: MediaPipe 정규화 좌표는 x를 너비로, y를 높이로 나눈 값이다. 픽셀 비율을 되살리려면 dx·W : dy·H = dx·(W/H) : dy 이므로 x에 W/H를 곱하는 것이 맞다. 세로 화면(720x1280, aspect 0.5625)에서는 x 성분이 줄어드는 방향이며 올바르다.
- 경계값: `best.visibility >= minVisibility`, 정확히 기준값이면 통과. Task 문구("기준 미만이면 null")와 일치.
- 동률: `right > left`일 때만 right, 그 외 left. 계약 일치.
- anglesForSide는 visibility와 무관하게 계산하고 거르는 일은 selectSide만 한다. 계약 의도와 맞음.
